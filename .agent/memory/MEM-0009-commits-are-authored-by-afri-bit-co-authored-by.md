## What

Every commit is authored by `afri-bit` (`git config user.name afri-bit`, with an afri-bit GitHub noreply email; the exact command is in `.claude/skills/git-commit/SKILL.md`). A `Co-authored-by` trailer is allowed for a person or tool that helped, and is never required. Commits and PR descriptions still carry no `Signed-off-by`, session link or "generated by" line.

Branches are named `<type>/<name>` with type bugfix, feature, hotfix, release, task or chore. Never `claude/`.

## Why it matters

The maintainer wants one attributable author identity in the history, and wants helpers credited through trailers. Both rules are enforced by `guard-git.sh` and the `repo-rules` CI workflow.

## How to apply

Check `git config user.name` before the first commit of a session. Commit through `/git-commit`. See the constitution (Branching, Commit identity) and docs/decisions/0014-branch-prefixes-commit-identity-and-release-gate.md.
