## What

Commits and pull request descriptions never carry `Co-authored-by`, `Signed-off-by`, "generated by" lines or session links. The `git-commit` skill states this rule and the owner's other repositories repeat it.

## Why it matters

It is the owner's convention. A default attribution footer from a tool would break it.

## How to apply

Commit through `/git-commit` with a HEREDOC message. After committing, read `git log -1 --format=%B` and amend an unpushed commit if a trailer appeared.
