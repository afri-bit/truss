## What

Every commit is authored by `afri-bit` with the maintainer's email given in `CLAUDE.md` and the
`/git-commit` skill. Claude may be named as co-author; a commit Claude wrote ends with the Claude
`Co-authored-by` trailer shown in the `/git-commit` skill. The trailer is allowed, never required. No
`Signed-off-by`, session links or "generated by" lines.

## Why it matters

The maintainer decided this on 2026-11-14 (constitution 2.1.1, Commit identity). CI and `guard-git.sh`
reject a commit whose author is not afri-bit or uses a tool address; trailers are not checked.

## How to apply

Set the identity from `CLAUDE.md` before the first commit of a session. Commit through `/git-commit`.
